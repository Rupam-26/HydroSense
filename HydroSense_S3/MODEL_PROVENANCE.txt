ACTIVE FIRMWARE MODEL
---------------------

Model name:
Tiny_32_16_8

Runtime format:
Direct FP32 neural-network inference implemented in C++.

Architecture:
3 -> 32 -> 16 -> 8 -> 1

Hidden activation:
ReLU

Output activation:
Linear

Parameters:
801

Input order:
1. DHT_temp
2. DHT_humidity
3. water_temp

Embedded FP32 weights:
include/tinyml/HydroSense_TDS_FP32_weights.h

SHA-256 of the FP32 weights header:
e31733fdfc2cee7c1e303282d4ffd15715fb3f44ff035e1a83c391e8c7adeb31

Preprocessing constants:
include/tinyml/HydroSense_TDS_constants.h

Recorded FP32 evaluation:
MAE = 90.1565 ppm

The firmware performs FP32 inference directly. It does not use TensorFlow,
TensorFlow Lite, TensorFlow Lite Micro, INT8 inference, quantization, input
clamping, or synthetic replacement values.


TRAINING ARTIFACT
-----------------

Original training-model reference:
models/HydroSense_TDS_TinyML.keras

The original Keras training artifact is not included in this S3 firmware
folder. Therefore, retraining and independent weight-export verification
require the original training notebook, dataset and Keras model.
