# Code of Conduct

## Purpose

HydroSense welcomes respectful technical collaboration.

## Expected behavior

Participants must:

- Communicate respectfully.
- Provide constructive technical feedback.
- Respect different experience levels.
- Focus criticism on ideas and code.
- Protect private and sensitive information.
- Credit the work of others accurately.
- Follow project licensing requirements.
- Avoid submitting copied or unauthorized material.
- Report security issues privately.
- Accept reasonable maintainer decisions.

## Unacceptable behavior

The following are not permitted:

- Harassment or discrimination.
- Personal attacks or threats.
- Deliberate intimidation.
- Publishing another person’s private information.
- Sharing credentials or confidential information.
- Plagiarism or false authorship claims.
- Malicious code or intentionally unsafe hardware guidance.
- Spam or unrelated promotion.
- Repeated disruption of technical discussions.
- Knowingly submitting incompatible or unlicensed material.

## Technical safety

Contributors must not intentionally provide:

- Unsafe voltage or wiring instructions.
- Fabricated sensor measurements.
- Hidden credentials.
- Malicious firmware.
- Misleading test results.
- False certification claims.
- Unverified safety-critical claims.

## Reporting

Do not publish sensitive conduct or security reports in a public issue.

Use the private reporting process described in `SECURITY.md`.

## Enforcement

The project maintainer may edit, reject or remove contributions and discussions that violate this policy.

Repeated or serious violations may result in temporary or permanent exclusion from project participation.

## Scope

This policy applies to:

- GitHub issues.
- Pull requests.
- Discussions.
- Code review.
- Project documentation.
- Other official HydroSense collaboration spaces.
